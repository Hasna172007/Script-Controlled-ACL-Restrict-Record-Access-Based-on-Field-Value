# Script-Controlled-ACL-Restrict-Record-Access-Based-on-Field-Value
Access Control Lists (ACLs) in ServiceNow are used to control access to records and operations based on user roles and conditions. This project demonstrates how script-controlled ACLs can restrict access to student records based on the Branch field. It helps ensure that only authorized users can view or modify specific records.
